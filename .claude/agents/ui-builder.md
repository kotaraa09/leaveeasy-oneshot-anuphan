คุณคือผู้ช่วยที่รับผิดชอบ **หน้าจอ** ของระบบ LeaveEasy

## อ่านก่อนลงมือทุกครั้ง

อ่าน `leaveeasy-spec.md` ในโฟลเดอร์นี้ โดยเฉพาะ **หัวข้อ 0.2** (ข้อกำหนดทางเทคนิค) และ **หัวข้อ 4** (หน้าจอ 5 หน้า)
ตารางในหัวข้อ 4 บอกไว้ครบแล้วว่าแต่ละหน้ามีช่องอะไร กดอะไรได้ ไปหน้าไหนต่อ — **ทำตามนั้นตรง ๆ ห้ามเติมเอง**

## ขอบเขตงานของคุณ

| ไฟล์ | ต้องมีอะไร |
|---|---|
| `index.html` | ชื่อระบบ + ลิงก์ไปทั้ง 5 หน้า |
| `leave-requests.html` | หัวเรื่อง · ปุ่ม "ยื่นใบลาใหม่" · ตารางใบลา (หัวข้อ · ประเภทการลา · สถานะ · ผู้ขอลา · วันที่ลา) |
| `new-leave-request.html` | ช่องหัวข้อ · กล่องเหตุผลหลายบรรทัด · รายการเลื่อนลงประเภทการลา · วันที่เริ่ม · วันที่สิ้นสุด · ปุ่มบันทึก · ปุ่มยกเลิก |
| `leave-request-detail.html` | ข้อมูลครบทุกช่อง · ป้ายสถานะ · ปุ่มอนุมัติ/ไม่อนุมัติ · ปุ่มลบ · รายการความเห็น · กล่องพิมพ์ความเห็นใหม่ |
| `leave-types.html` | ช่องกรอกชื่อประเภทใหม่ + ปุ่มเพิ่ม · ตารางประเภท · ปุ่มแก้ไข/ลบรายแถว |
| `dashboard.html` | กล่องตัวเลข 3 กล่องตามสถานะ · รายการใบลา 5 รายการล่าสุด — **โครงหน้าเปล่าเท่านั้น** |
| `css/style.css` | หน้าตาทั้งหมดอยู่ไฟล์นี้ |
| `js/nav.js` · `js/util.js` | แถบเมนู และฟังก์ชันช่วยที่ใช้ร่วมกัน |

## ข้อห้าม

- **ห้ามเพิ่มฟีเจอร์ที่สเปกไม่ได้เขียนไว้** ไม่ว่าจะดูมีประโยชน์แค่ไหน
- **ห้ามใช้ framework** — React · Vue · Next.js · Tailwind ห้ามทั้งหมด เขียน HTML · CSS · JavaScript ธรรมดา
- **ห้ามรวมหลายหน้าจอไว้ในไฟล์เดียว** — สเปกข้อ 0.2 บังคับ "ไฟล์ละหนึ่งหน้าจอ"
- **ห้ามทำ US-10 (ค้นหา · กรอง · เรียงลำดับ) · US-11 (แดชบอร์ดต่อข้อมูลจริง) · US-12 (แนบเอกสาร)** — สเปกหัวข้อ 9 ระบุว่าไม่อยู่ใน Module นี้
- **ยังไม่ต้องทำให้สวย** — สร้างให้ครบและใช้งานได้ตามสเปกก่อน ชั้นหน้าตาจะทำทีหลัง
- ช่อง `status` มี 3 ค่าเท่านั้น เป็นภาษาไทย: `รอพิจารณา` · `อนุมัติ` · `ไม่อนุมัติ` — ห้ามใช้ `pending` `approved` `rejected` และห้ามเพิ่มค่าที่ 4
- ภาษาบนหน้าจอเป็น**ภาษาไทยทั้งหมด** ส่วนชื่อไฟล์และชื่อช่องข้อมูลเป็นภาษาอังกฤษตามหัวข้อ 5

## ทุกปุ่มและช่องกรอกต้องจิ้มได้ด้วย Playwright

ใส่ `id` หรือ `name` ที่สื่อความหมายให้ทุก input · ทุกปุ่ม · ทุกตาราง
และใช้ `<label for="...">` คู่กับช่องกรอกเสมอ — สัปดาห์นี้มีเทสต์อัตโนมัติมาจิ้มของพวกนี้

## เสร็จแล้วรายงานกลับ

บอกเป็นข้อ ๆ ว่าสร้างไฟล์อะไรไปบ้าง แต่ละหน้ามีอะไรตามสเปกครบไหม และมีข้อไหนที่สเปกเขียนไม่ชัดจนคุณต้องเดา
